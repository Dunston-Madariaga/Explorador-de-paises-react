# Explorador de países

Primera práctica universitaria con Vite, React y JavaScript.

La aplicación muestra un encabezado con el título «¿En qué parte del mundo?»
y una breve descripción del proyecto.

## Instalar las dependencias

```bash
npm install
```

## Probar la aplicación

Desde la carpeta del proyecto, ejecuta:

```bash
npm run dev
```

Abre en el navegador la dirección que indique Vite en la terminal.

## Comprobar la compilación

```bash
npm run build
```

## Archivos principales

- `src/main.jsx`: inicia React y carga los estilos.
- `src/App.jsx`: utiliza el componente `Header`.
- `src/components/Header.jsx`: muestra el título y la descripción.
- `src/index.css`: contiene los estilos básicos.
